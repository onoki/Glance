# Typography and controls

- Use bundled BigBlue TerminalPlus, an unmodified VileR font licensed CC BY-SA 4.0. Keep its attribution, README and license with the font.
- It has a regular face only. Do not use bold, italic, or synthesized weights for UI labels, buttons, navigation, or headings. Use color, fill, borders, and spacing for emphasis.
- Exception explicitly approved by the user: task rich text retains synthetic bold and italic, including Ctrl+B/Ctrl+I and existing saved marks. Do not strip those marks or silently substitute another font.
- The font's native grid is 8×12. At the user's 150% Windows scaling, 8 CSS px maps to 12 device pixels (1× the native height, the smallest aligned size). Use the shared 8px size tokens and 16px control height, rather than fractional rem sizes or arbitrary smaller labels. Recheck pixel-grid alignment when introducing another size or zoom option.
- Shared controls have neutral, emphasized, and danger variants in `src/styles/controls.css`. Avoid view-specific font, weight, padding, or selected-state overrides. Keep the dashed empty-editor insertion target distinct.
- Ordinary unpressed controls and task text use the dark neutral `--text-main` color consistently, with no alternating row colors. Preserve meaningful link, highlight, completed-task, selected-control, and danger colors. Navigation buttons and the Settings/New window icons share a 1px gap defined in `controls.css`.
- Task action bars appear only while focus is within that task (including its action controls), never on row hover. They must not reserve row height or shift text. On window blur, dismiss the bar and all menus and remove them from hit testing. Restored focus alone must not reopen them. A click on a task may reveal its bar after the click target has been resolved (in the bubbling click handler, never pointerdown or focusin), including the first click back into Glance. Other tasks and previously open menus stay dismissed. Editing keystrokes may also restore the focused task bar.
- Preserve the 8px base font size. Do not reinstate automatic text-origin correction: its measurement/write feedback can oscillate after zoom or DPI changes. Keep grayscale rendering. Zoom uses practical intermediate steps, a reset, and an explained asterisk for near-native-grid sizes; crispness is a hint, not a guarantee. Desktop zoom preferences belong to the current PC and monitor, not the portable database. Avoid transformed text containers.
- Keep task columns compact but provide a 64px blank insertion tail. Follow the active caret near viewport edges without snapping earlier edits to the list end.
- Task menus require deliberate click/keyboard activation, never hover. Keep Move versus Send a copy explicit. Undo notifications must target the announced operation, never a later edit.
- The Windows desktop host requests grayscale text antialiasing (`--disable-lcd-text`) before creating WebView2 windows. This removes LCD color fringes rather than all smoothing; do not claim CSS `font-smooth` disables smoothing on Windows or change system-wide settings.
- Keep + Person neutral like Rename/Archive. Person switches commit the selected person and fetched rows together and must not animate outgoing/incoming people as task reorders.
- The focus outline must connect the full-width action bar to the left task edge; hide both lines with dismissed controls or during dragging. Empty-task Delete focuses the following title at position 1; Backspace retains backward focus.
- Explicit task focus requests after editing must resume that destination's dismissed controls and remeasure the toolbar after layout. Native focus restoration remains insufficient. Focused rows must not transform their fixed-position toolbar during list movement.
- Backspace title merging uses the preceding visible task within the current Dashboard category, including weekday grouping order; never the global interleaved mainTasks array. The first row cannot merge across columns.

- Boundary Delete/Backspace joins logical lines, not just task titles. Use `taskJoin.js` for shared rich-document transformations. Forward Delete consumes the first subcontent line before the next task; cross-task joins append the lower title to the upper task's final subcontent paragraph (or title if there is no subcontent). Preserve caret position, nesting, remaining lines, and rich marks. Keep joins within the current column/person and recoverable with Undo.

- Plain Left/Right cross exact collapsed editor boundaries within the current column/person, including title/subcontent; preserve modified arrows and selections. Do not create a task at the last Right boundary.

- Up/Down navigation must never create tasks or cross Dashboard columns. At editor boundaries, Down enters the first subcontent paragraph at its end; Up from its first visual line returns to the title end. Leave wrapped-line navigation, selections and modified arrows native. The whole insertion tail darkens slightly on hover.

- Cross-task Up/Down preserve beginning/end caret intent; an empty source counts as beginning. Middle positions preserve screen X as closely as possible on the destination visual line. Helper windows use a lightly blue top bar and plain Helper window label without a border or background; keep task surfaces and typography unchanged.

- Enter at the end of a title with existing subcontent prepends an empty bullet and focuses it. Preserve title-only task creation and middle-title splitting. People scrollbars belong at the window edge; the task content can retain a narrower readable width. Use the single shared ProseMirror typography rule for plain titles and subcontent.

- This week must expose today through Sunday even when empty, retaining past groups only with visible tasks. Never automatically redate unfinished tasks. Use the shared currentWeekDays helper for the Move picker and day targets; disable past assignments, stop day-drop propagation, and preserve Undo and task focus.

- Empty nested-list deletion must use scoped ProseMirror transactions, never whole-document setContent based on a local list child count. Only the sole outer list can qualify as the entire subcontent. Preserve parents, siblings, rich marks and populated descendants; use a resolved text selection and retain native Undo/Redo. Enter may exit only the final outer list. Keep nestedListSafety.test.js and task-key-handler regressions covering these boundaries.

- Keep the compact Mo-Su picker immediately below This week without a duplicate heading. Creating an adjacent task via Enter, title split, or subcontent promotion inherits the source scheduled date; explicit moves and independent additions retain their own scheduling rules.

- Removing an empty bullet with Backspace places the caret at the preceding text line end, falling forward only when no preceding line exists. All button hover selectors must exclude :disabled; retain disabled appearance and tooltips.

- Tab/Shift+Tab restructuring preserves intentional blank bullets on both sides, including blank-only lists. Blur must not delete content. Tab merges flush pending saves before reading snapshots and serialize across the list; use current visible neighbours within the same category/person. Carry acknowledged save revisions into retained dirty snapshots; never bypass real conflict checks. Retire a merged source through recoverable deletion so Undo preserves its identity.

- This week column headings use full weekday names; the Move picker remains compact Mo-Su. Every column can maximize below the top navigation and restore without losing widths or the normal horizontal viewport. Restore the regular view if its maximized category disappears or source navigation must reveal a task in another column.
- Send/Tags menus are multi-select: clicking a label toggles its checkbox and keeps the menu open; outside clicks and Escape dismiss it. Exclude labels, task bars and floating menus from Dashboard background panning. Preserve focus during Send label clicks so its focus-only toolbar stays available.
- Image display and handle resizing must never exceed loaded intrinsic dimensions. Fit large images to the container, preserve aspect ratio and smaller saved sizes, and bound legacy oversized widths on load without rewriting unrelated text. Whole-task drags use their own MIME type and capture handlers to bypass rich-text drop cursors; indicate only before/after a whole task using its midpoint. Preserve targets across child paragraph events and calculate weekday neighbours within the target day. Flush pending saves before drag metadata writes and let People editors acknowledge the resulting revision before further edits.
- History activity defaults expanded when populated, omits empty charts, and remembers the user's disclosure choice in local UI preferences. Move completed includes today's Dashboard and People notes, retaining person attribution and restoration to the original list. Flush pending edits first; never archive open or deleted notes.
