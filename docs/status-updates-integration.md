# Status Updates retired

The Status Updates tab, task report-marker controls and Ctrl+7, report endpoints, Azure DevOps/Outlook readers, authentication setup and Excel/PowerPoint generators were removed on October 19, 2026 at the user’s request.

Existing database columns and tables, saved compressed reports in `data/status-updates/`, and rich-document attributes remain intact. Backups, restores and portable exports retain legacy data. The old report schema remains solely for validating archived/backup report files; it is no longer offered as a report feature. No authentication or external collection is initiated by the application.
